# 👹 高校入試対策シリーズ ～入試基本計算～

沖縄県立高校入試数学の**大問1（基本計算）**に向けた、中学生向けの練習アプリです。ビルド工程のないVanilla HTML/CSS/JavaScriptの静的アプリで、単独で動きます。

- 権利・プライバシー: [NOTICE.md](./NOTICE.md) ／ 依存関係: [DEPENDENCIES.md](./DEPENDENCIES.md) ／ ライセンス: [LICENSE](./LICENSE)
- 画面上の権利表記: `legal.html`（ホームの「このアプリについて」から開きます）

## できること

1セット**10問**。**10問中9問以上**でクリアです。沖縄県立高校入試数学・大問1の実出題実績に基づき、正負の数・分数・小数・平方根・単項式・一次式の6型を問います。

| Q | 内容 |
|---:|---|
| 1 | 正負の数の加減（2項） |
| 2 | 分数の加減（通分1回） |
| 3 | 小数の四則（小数で答える） |
| 4 | 単項式の乗法・累乗（1文字） |
| 5 | 平方根の簡単化・同類根号の加減 |
| 6 | 一次式の分配と同類項の整理 |
| 7 | 正負の数の加減・乗除を含む3項混合 |
| 8 | 分数の乗除 |
| 9 | 単項式の除法を含む乗除 |
| 10 | 平方根の積・商・有理化、または3項の加減 |

### 学習の流れ

`ホーム → 10問 → 結果 → （任意で）まちがいだけ復習` の3画面だけです。設定画面や診断画面はありません。

- **提出は1問1回**です。間違えると、自分の答え・正しい答え・考えられる原因・全部の手順・次の注意が出て、次へ進みます。途中で修正問題は挟みません。
- **ヒントは1つのボタンで3段階**開きます。ヒント1は着眼点、ヒント2は最初の1手（答えは出しません）、ヒント3は完全な解説です。**ヒント3を開くと、その問題はギブアップとして不正解で確定**し、入力できなくなります。
- **まちがいだけ復習**は、間違えた技能と同じ構造で数値だけ違う問題を出します。進捗の分母は残り問題数に応じて変わり、**全問正解になるまで繰り返せます**。復習の結果は得点・最高記録・履歴には入りません。
- 途中で「ホームへ」を押すと、履歴に「中断」として残ります。

### 問題を解くときの入力

数式は MathLive の入力欄に書きます。半角で入力しますが、全角で打っても内部で半角に直して採点します。入力補助ボタン（`√`・分数・指数・`+`・`-`・変数・**`→`**）があります。**`→` は指数や根号の外に出るためのボタン**で、`8a^2b` のように指数の右へ続けて書くときに使います。

答えは**最も簡単な形**で書きます。値が合っていても、約分していない・`√8` のまま・分母に根号が残る・同類項がまとまっていない場合は、「値は合っています。形を最後まで整えよう」と出て正解にはなりません。分数はスラッシュ（`5/6`）で書いても正解です（画面の表示は上下の分数に直されます）。帯分数は使えません。

問題画面では、**画面全体に指・スタイラス・マウスで筆算を書けます**。書いた内容は採点に使わず、保存もしません。「次へ」で消えます。

## 動かし方

ES module を使うため、`file://` では動きません。ローカルで確認するときは、このフォルダでWebサーバを立ててください。

```bash
python3 -m http.server 8000
```

そのうえで `http://localhost:8000/index.html` を開きます。

## 公開前の内部検証

公開前にseed 0〜999について、10スロット分の問題生成と採点を検査しています。主な検査項目は次のとおりです。

- 同じseedから常に同じ問題ができること（100回再生成して完全一致）
- 分母0・根号内の負数・二重根号・負の指数・0乗・帯分数が生成されないこと
- 根号が最簡形で一意になること、単項式の指数が1〜3であること
- **自分が生成した正答を、自分の採点器が必ず正解と判定すること**
- 正解の別表現（項順・変数順の入替、余分な括弧、係数1の明示、スラッシュ分数、全角）が正解になること
- 未整理の答え・誤答・近似値・壊れた入力が、それぞれ正しく区別されること
- ヒント1・2に最終の答えが含まれないこと
- 1セット内で同じ型が重複しないこと、必須の分野が毎セット出ること
- 復習問題が元の問題と同じ技能で、数値だけ違うこと

問題生成に `Math.random()` を使っていないことも、テスト側で `Math.random` を例外にすり替えて機械的に確認しています。

## 実装上の要点

- **問題はseedから決定的に生成します。** `sessionSeed`・モード・スロット番号・courseId から FNV-1a で `templateSeed` を作り、そこから `questionSeed` を派生させ、`mulberry32` で乱数を回します。問題文・正答・ヒント・解説はすべて同じ生成パラメータから作るため、食い違いません。
- **採点に浮動小数を使いません。** 答えは「平方因数を外した根号 × 変数の指数辞書 → BigIntの有理数」という1つの正規形に統一し、厳密比較だけで正誤を決めます。`eval` と `Function` は使いません。近似値（`3√2` に対する `4.243` など）は必ず不正解になります。
- **値の正しさと答案の形を別々に判定します。** 値は正規形で、形は構文木で見ます。正規形は「未約分」「`√8` のまま」といった情報を失うため、形式違反は構文木からしか検出できません。
- **生徒の入力をそのまま数式として組版しません。** パースに成功した答えは構文木から組み直したLaTeXを表示し、失敗した入力は素のテキストとして出します。MathJaxからは `require`・`html`・`textmacros` を外しています。
- **保存は端末内の2キーだけ**（`nyushi-series:v2:course:exam-calculation` / `nyushi-series:v2:history:exam-calculation`）。読み書き削除はすべて例外を捕まえ、localStorageが使えない端末ではメモリに退避します。壊れたデータが入っていても起動します。
